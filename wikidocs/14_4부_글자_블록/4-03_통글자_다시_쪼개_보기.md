# 4-3 통글자 다시 쪼개 보기

> 🎯 **오늘의 목표**: 1부에서 통으로 읽던 낱말을 자음과 모음으로 쪼개 본다.
> ⏱ **시간**: 10분 · 🧺 **준비물**: 1부 글자 카드, 가위(종이 카드를 실제로 자를 때), 스티커

## 1. 복습 (1~2분)

가나다 노래를 한 번 불러요.

## 2. 오늘의 글자 (3분)

| 낱말 | 쪼개면 |
|:---:|:---:|
| **사과** | 사 = ㅅ + ㅏ · 과 = ㄱ + ㅗ + ㅏ |
| **나비** | 나 = ㄴ + ㅏ · 비 = ㅂ + ㅣ |
| **엄마** | 엄 = ㅇ + ㅓ + ㅁ · 마 = ㅁ + ㅏ |

**이렇게 말해 주세요**

- "사과 속에 우리가 아는 친구들이 숨어 있었어! 시옷이랑 아!"
- '엄'처럼 아래에 붙은 친구(받침)는 5부에서 자세히 만나요.

## 3. 놀이 (3~4분)

### 놀이 A — 글자 가위 놀이

1. 종이에 '사과'를 크게 써요.
2. 아이와 함께 글자 하나씩 가위로 잘라요.
3. 잘린 글자를 보며 숨은 자음·모음을 찾아 색칠해요.

### 놀이 B — 웹 놀이터 쪼개기

글자를 누르면 자음·모음·받침이 색깔 블록으로 나뉘고 하나씩 소리가 나요.

## 4. 마무리 (1분)

- 스티커 1개를 붙여요.
- 오늘 읽은 것을 다시 말해 주세요. "오늘 이걸 해냈어! 대단하다!"

## ✅ 확인하기

- [ ] 두 글자 낱말을 글자 단위로 나눌 수 있다
- [ ] 글자 속 자음과 모음을 찾을 수 있다

다 못 해도 괜찮아요. 다음 시간에 같은 단원을 한 번 더 하면 됩니다.

## 💡 부모 팁

- 통글자와 자모가 연결되는 중요한 단원이에요. 서두르지 말고 여러 번 해요.
