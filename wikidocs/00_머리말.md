# 머리말 — 이 책을 쓰는 방법

이 책은 만 4세 무렵 아이와 부모가 **하루 10분**, 놀이로 한글을 만나는 수업 대본입니다.

## 이 책의 짜임

| 부 | 내용 | 대략 기간 |
|---|---|---|
| 0부 말소리 놀이 | 귀로 소리를 나누고 비교하기 | 2주 |
| 1부 그림 통글자 | 그림과 함께 낱말을 통째로 읽기 | 6~8주 |
| 2부 모음 친구들 | ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ ㅑ ㅕ ㅛ ㅠ | 4~6주 |
| 3부 자음 친구들 | ㄱ부터 ㅎ까지 14자 | 6~8주 |
| 4부 글자 블록 | 자음 + 모음 = 글자 | 4~6주 |
| 5부 받침 글자 | ㅇ ㄴ ㅁ ㄹ ㄱ ㅂ 받침 | 6~8주 |
| 6부 짧은 문장 | 두세 낱말 문장 읽기 | 계속 |

기간은 참고일 뿐이에요. **아이 반응을 보고** 넘어가세요. 한 단원을 여러 번 해도 좋습니다.

> ㄱ, ㄴ, ㄷ을 하나도 모르는 아이라면 부모 가이드의 **「한글을 처음 만나는 아이라면」**을 먼저 읽어 주세요. 0부부터 차례로 하면 됩니다.

## 한 단원 = 한 번의 수업

모든 단원은 같은 순서로 되어 있어요.

1. **복습** (1~2분) — 지난 시간 것 다시 보기
2. **오늘의 글자** (3분) — 그림 → 소리 → 글자
3. **놀이** (3~4분) — 몸 놀이 또는 웹 놀이터
4. **마무리** (1분) — 스티커와 칭찬
