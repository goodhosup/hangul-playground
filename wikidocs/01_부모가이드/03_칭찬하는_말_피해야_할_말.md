# 칭찬하는 말, 피해야 할 말

## 이렇게 말해요

| 상황 | 말 |
|---|---|
| 맞혔을 때 | "우와, '사과'를 찾았네!" (무엇을 했는지 구체적으로) |
| 틀렸을 때 | "오, 비슷한 걸 골랐네. 다시 찾아볼까?" |
| 머뭇거릴 때 | "엄마가 먼저 읽어 줄게. 사-과!" |
| 끝났을 때 | "오늘 글자 세 개나 만났어. 대단하다!" |

## 피해야 할 말

- "이거 어제 했잖아, 왜 몰라?"
- "이건 뭐라고 써 있어?" (시험처럼 묻기)
- "옆집 ○○는 벌써 다 읽는대."

## 기억하세요

1. 아이가 그만하고 싶어 하면 멈춘다.
2. 시험하지 말고 먼저 읽어 준다.
3. 하루 새 낱말은 2~3개까지.
4. 생활 속 글자(간판, 과자 봉지, 엘리베이터 버튼) 찾기가 최고의 복습.
5. 화면 놀이는 하루 10분 이내, 반드시 함께.
