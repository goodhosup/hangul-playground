# 1-1 맛있는 과일

> 🎯 **오늘의 목표**: 과일 그림을 보고 과일 이름 글자를 "모양 그대로" 읽어 본다.
> ⏱ **시간**: 10분 · 🧺 **준비물**: 과일 그림 카드 5장(또는 실제 과일 1~2개), 스티커

## 1. 복습 (1~2분)

손뼉 놀이로 몸을 풀어요. "사과" 짝짝, "바나나" 짝짝짝!

## 2. 오늘의 글자 (3분)

그림 → 소리 → 글자 순서로 보여 주세요. 손가락으로 글자를 짚으며 천천히 읽어 줍니다.

| 그림 | 글자 |
|:---:|:---:|
| 🍎 | **사과** |
| 🍌 | **바나나** |
| 🍇 | **포도** |
| 🍓 | **딸기** |
| 🍉 | **수박** |

**이렇게 말해 주세요**

- "이건 빨간 **사과**네! 여기 '사과'라고 써 있어."
- "사과는 글자가 몇 개일까? 사-과, 두 개!"

> 하루에 새 단어는 2~3개면 충분해요. 아이가 좋아하는 것부터 골라 주세요.

## 3. 놀이 (3~4분)

### 놀이 A — 과일 가게 놀이

1. 카드 3장을 바닥에 펼쳐요.
2. 엄마·아빠가 손님이 되어 "**포도** 주세요!" 하고 말해요.
3. 아이가 카드를 골라 건네주면 "고맙습니다!" 하고 받아요.
4. 역할을 바꿔서 아이가 손님이 되어 주문해 봐요.

### 놀이 B — 냉장고 탐험

냉장고나 과일 바구니에서 진짜 과일을 꺼내 카드 옆에 놓아 보세요. 글자와 실물이 연결되면 기억이 오래가요.

## 4. 마무리 (1분)

- 스티커 1개를 붙여요.
- 오늘 읽은 것을 다시 말해 주세요. "오늘 이걸 해냈어! 대단하다!"

## ✅ 확인하기

- [ ] 그림을 보고 과일 이름을 말할 수 있다
- [ ] 글자 카드 2장 중 말한 과일을 고를 수 있다
- [ ] 손뼉으로 글자 수를 셀 수 있다

다 못 해도 괜찮아요. 다음 시간에 같은 단원을 한 번 더 하면 됩니다.

## 💡 부모 팁

- "이거 뭐라고 써 있어?" 하고 시험하듯 묻기보다 먼저 읽어 주세요.
- 마트 과일 코너 가격표의 글자를 함께 찾아보세요.
- "바나나"처럼 같은 글자가 반복되는 단어는 금방 알아봐요. "'나'가 두 번 있네!"
