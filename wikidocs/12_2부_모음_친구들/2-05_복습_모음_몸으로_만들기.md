# 2-5 복습 · 모음 몸으로 만들기

> 🎯 **오늘의 목표**: 기본 모음 10개를 몸으로 만들고 소리를 낸다.
> ⏱ **시간**: 10분 · 🧺 **준비물**: 모음 카드 10장, 넓은 공간, 스티커

## 1. 복습 (1~2분)

ㅏ ㅓ ㅗ ㅜ 카드를 빠르게 넘기며 소리 내기.

## 2. 오늘의 글자 (3분)

| 모음 | 소리 | 몸으로 만들기 |
|:---:|:---:|---|
| **ㅏ** | 아 | 차렷, 오른팔 옆으로 |
| **ㅓ** | 어 | 차렷, 왼팔 옆으로 |
| **ㅗ** | 오 | 엎드려 누워 머리 위로 손 하나 |
| **ㅜ** | 우 | 엎드려 누워 발 아래로 다리 하나 |
| **ㅡ** | 으 | 옆으로 길게 눕기 |
| **ㅣ** | 이 | 차렷 |
| **ㅑ ㅕ ㅛ ㅠ** | 야 여 요 유 | 위 자세에서 손가락 두 개 |

## 3. 놀이 (3~4분)

### 놀이 A — 모음 체조

1. 부모가 카드를 들면 아이가 몸으로 만들고 소리 내요.
2. 이번엔 아이가 몸으로 만들고 부모가 맞혀요.
3. 틀린 척하면 아이가 신나게 고쳐 줘요.

### 놀이 B — 웹 놀이터 소리 퀴즈

소리를 듣고 모음을 골라요. 그림 단어의 첫 글자에 숨은 모음을 찾는 문제도 나와요.

## 4. 마무리 (1분)

- 스티커 1개를 붙여요.
- 오늘 읽은 것을 다시 말해 주세요. "오늘 이걸 해냈어! 대단하다!"

## ✅ 확인하기

- [ ] ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ를 보고 소리 낼 수 있다
- [ ] ㅏ와 ㅓ, ㅗ와 ㅜ를 구별할 수 있다

다 못 해도 괜찮아요. 다음 시간에 같은 단원을 한 번 더 하면 됩니다.

## 💡 부모 팁

- ㅏ/ㅓ, ㅗ/ㅜ 헷갈림은 이 나이에 아주 흔해요. 몸 방향으로 기억하게 해 주세요.
- ㅑ ㅕ ㅛ ㅠ는 "팔이 하나 더!"로 충분해요.
