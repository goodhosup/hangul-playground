1. 위키독스 로그인 → 새 책 만들기 (제목: 우리 아이 첫 한글: 4살 한글 놀이책)
2. 위 목차 순서대로 페이지를 만들어요. 들여쓴 항목은 바로 위 페이지의 하위 페이지로 만들어요.
3. 각 파일 내용을 복사해 페이지 편집기에 붙여넣어요(첫 줄 `#` 제목은 페이지 제목과 같아요).
4. 처음에는 비공개로 두고 1부까지 확인한 뒤 공개로 바꿔요.
