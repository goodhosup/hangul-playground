# 0-3 손뼉 치며 글자 세기

> 🎯 **오늘의 목표**: 낱말을 글자(음절) 단위로 끊어 말하며 글자 수를 센다.
> ⏱ **시간**: 10분 · 🧺 **준비물**: 몸(손뼉), 스티커

## 1. 복습 (1~2분)

처음 소리 짝꿍 2쌍을 다시 들려줘요. 가방·가위, 오리·오이!

## 2. 오늘의 글자 (3분)

| 그림 | 낱말 | 손뼉 |
|:---:|:---:|:---:|
| 🐶 | 개 | 👏 |
| 🍎 | 사·과 | 👏👏 |
| 🍌 | 바·나·나 | 👏👏👏 |
| 👴 | 할·아·버·지 | 👏👏👏👏 |

**이렇게 말해 주세요**

- "사-과! 손뼉을 몇 번 쳤지? 두 번! 사과는 글자가 두 개야."
- 글자 하나에 손뼉 한 번. 이것이 나중에 글자를 읽는 기초가 돼요.

## 3. 놀이 (3~4분)

### 놀이 A — 손뼉 로봇

1. "로봇 모드 켜기!" 하고 딱딱한 로봇 말투로 바꿔요.
2. 로봇처럼 글자마다 손뼉 치며 말해요. "할-아-버-지!"
3. 아이가 낱말을 정하면 부모가 로봇이 되어 따라 해요.

### 놀이 B — 계단 뛰기

글자 수만큼 계단을 오르거나 제자리 점프를 해요. 바나나는 점프 세 번!

## 4. 마무리 (1분)

- 스티커 1개를 붙여요.
- 오늘 읽은 것을 다시 말해 주세요. "오늘 이걸 해냈어! 대단하다!"

## ✅ 확인하기

- [ ] 손뼉을 치며 낱말을 끊어 말할 수 있다
- [ ] 2~3글자 낱말의 글자 수를 맞힐 수 있다

다 못 해도 괜찮아요. 다음 시간에 같은 단원을 한 번 더 하면 됩니다.

## 💡 부모 팁

- 받침이 있는 '수박'도 '수·박' 두 번이에요. 글자 하나 = 손뼉 하나.
- 자기 이름 글자 수를 세면 아이가 특히 좋아해요.
