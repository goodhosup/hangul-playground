# 0-2 첫소리가 같은 말

> 🎯 **오늘의 목표**: 두 낱말의 처음 소리가 같은지 듣고 구별한다.
> ⏱ **시간**: 10분 · 🧺 **준비물**: 그림 카드(가방·가위, 바나나·바다 등), 스티커

## 1. 복습 (1~2분)

지난 시간 말 기차를 한 번 더 해요. 사과 → 과자 → 자전거!

## 2. 오늘의 글자 (3분)

| 처음 소리 | 같은 소리 친구들 |
|:---:|:---:|
| **가** | 🎒 가방 · ✂️ 가위 |
| **바** | 🍌 바나나 · 🌊 바다 |
| **사** | 🦁 사자 · 🍎 사과 |
| **오** | 🦆 오리 · 🥒 오이 |
| **토** | 🐰 토끼 · 🍅 토마토 |

**이렇게 말해 주세요**

- "가방, 가위. 둘 다 '가'로 시작하네! 입 모양도 똑같아."
- 처음 소리를 길게 늘여 말해 주세요. "가~~~방"

## 3. 놀이 (3~4분)

### 놀이 A — 소리 짝꿍 찾기

1. 그림 카드를 섞어 펼쳐요.
2. 부모가 한 장을 들고 "가방! 가방이랑 처음 소리가 같은 친구는?" 하고 물어요.
3. 아이가 짝을 찾으면 두 장을 나란히 놓아요.

### 놀이 B — 집 안 소리 사냥

"'바'로 시작하는 걸 찾아 오자!" 하고 집 안을 돌아다녀요. 바지, 바구니, 바나나…

## 4. 마무리 (1분)

- 스티커 1개를 붙여요.
- 오늘 읽은 것을 다시 말해 주세요. "오늘 이걸 해냈어! 대단하다!"

## ✅ 확인하기

- [ ] 처음 소리가 같은 두 그림을 고를 수 있다
- [ ] 처음 소리를 길게 따라 말할 수 있다

다 못 해도 괜찮아요. 다음 시간에 같은 단원을 한 번 더 하면 됩니다.

## 💡 부모 팁

- 정답이 아니어도 "오, 소리가 비슷하네!" 하고 받아 주세요.
- 이름 첫 소리 놀이도 좋아요. "민준이의 '민'이랑 같은 소리는?"
