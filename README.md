# 한글 놀이터

만 4세 아이가 부모와 함께 하루 10분씩 한글을 익히는 놀이형 웹페이지입니다.
위키독스 학습책『우리 아이 첫 한글』의 단원 번호(예: `1-1`)와 연결됩니다.

## 지금 들어 있는 것 (1차 버전)

| 페이지 | 내용 |
|---|---|
| `index.html` | 놀이터 지도, 1단계 단원 목록 |
| `cards.html?unit=1-1` | 그림 카드: 누르면 뒤집히며 글자와 소리, 한 번 더 누르면 한 글자씩 읽기 |
| `match.html?unit=1-1` | 짝 맞추기 5문제: 소리 듣고 / 글자 보고 그림 고르기, 그림 보고 글자 고르기 |
| `stickers.html` | 스티커판 (10칸) |
| `parent.html` | 부모방: 아이 이름, 소리 테스트, 진도, 초기화 (곱셈 문제로 잠금) |

1단계 그림 통글자 20단어(과일, 동물, 탈것, 가족)가 `data/words.json`에 있습니다.

## 소리

브라우저의 한국어 음성합성을 씁니다. 직접 녹음한 mp3를 `audio/`에 넣고 `words.json`의 `audio` 값에 경로를 적으면 그 파일을 먼저 재생합니다.

## 개인정보

진도와 아이 이름은 사용하는 기기의 브라우저에만 저장되며 어디에도 전송되지 않습니다.

## 단어 추가

`data/words.json`에 항목을 추가하고, 새 단원이면 `data/units.json`에도 추가합니다.

## 그림

그림은 기기 내장 이모지를 사용합니다.
